XMLHttpRequest (XHR) is a javascript tool that allows our webpage to talk to a server without refreshing the page.

    Your website -> Asks server for data -> server sends data back -> javascript can use that data

    for example, lets say we have a button called "Get user", when we click on it, our website asks the server
    to give us the data from user123, the server will send the data back in json format and our javascript can use it.

    XMLHttpRequest.readyState returns the current state XMLHttpRequest is in, 0 to 4.
    0 = unsent - client created, but open() not yet called
    1 = opened - open() has been called
    2 = headers recieved - send() has been called, headers and status are available
    3 = loading - Downloading, responseText holds partial data
    4 = done - complete

    open() will initialize the request, but won't send it yet. It will configure things
    open(method, url, async) (where async is boolean and default value is true)
    open() will move readyState from 0 to 1

    send() will send the request you configured with open, send(body). For get method no body is needed
    without send() request never actually happens, no matter what you passed to open.
    it moves readyState from 2, 3 and eventually 4.
